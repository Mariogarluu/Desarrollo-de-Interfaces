# Desarrollo de Interfaces

Asignatura de Desarrollo de Interfaces del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

## 📖 Descripción

Este repositorio contiene los proyectos, tareas y ejercicios realizados durante el curso de Desarrollo de Interfaces. El objetivo de la asignatura es aprender a diseñar y desarrollar interfaces de usuario efectivas y atractivas para aplicaciones multiplataforma.

## 📂 Estructura del Repositorio

- **[Tema 1/](Tema%201)** - Fundamentos de diseño web (HTML/CSS)
  - **[Tarea 1 Color/](Tema%201/Tarea%201%20Color)** - Ejercicio sobre teoría del color
  - **[Tarea 2 Fuentes/](Tema%201/Tarea%202%20Fuentes)** - Ejercicio sobre tipografías
  - **[Tarea 3 Icono/](Tema%201/Tarea%203%20Icono)** - Ejercicio sobre iconografía y SVG
- **[C#/](C%23)** - Proyectos en C# y WPF (Windows Presentation Foundation)
  - **[Hola_Mundo/](C%23/Hola_Mundo)** - Primer proyecto en C#
  - **[Tarea 3/](https://github.com/Mariogarluu/Ejercicios-Incio-C-)** - Ejercicios de inicio en C# (submodule)
  - **Proyectos WPF**: Basicos_WPF, DemoControles, Prueba, Zoo, MiLibreriaWPF, Proyecto_Series
  - **Ejercicios**: Múltiples ejercicios de WPF, eventos, delegados y controles de usuario
- **README.md** - Este archivo

## 🎯 Contenidos

### Tema 1: Fundamentos de Diseño Web
- **[Tarea 1 - Color](Tema%201/Tarea%201%20Color)**: Estudio de la teoría del color y su aplicación en diseño web
- **[Tarea 2 - Fuentes](Tema%201/Tarea%202%20Fuentes)**: Implementación de diferentes tipos de fuentes (Safe Fonts, Google Fonts, fuentes personalizadas)
- **[Tarea 3 - Iconos](Tema%201/Tarea%203%20Icono)**: Uso de iconografía SVG y Font Awesome en interfaces web

### C#: Desarrollo de Interfaces con C#
- **[Hola Mundo](C%23/Hola_Mundo)**: Proyecto inicial de consola en C#
- **[Tarea 3 - Ejercicios de Inicio](https://github.com/Mariogarluu/Ejercicios-Incio-C-)**: Ejercicios de inicio en C# (repositorio externo via submodule)
- **[Basicos_WPF](C%23/Basicos_WPF)**: Introducción a Windows Presentation Foundation
- **[DemoControles](C%23/DemoControles)**: Demostración de controles WPF
- **[Prueba](C%23/Prueba)**: Proyecto de prueba WPF
- **[Reloj](C%23/Reloj)**: Aplicación de reloj en C#
- **[Zoo](C%23/zoo)**: Aplicación de gestión de zoo con base de datos SQLite
- **[MiLibreriaWPF](C%23/MiLibreriaWPF)**: Librería personalizada de controles WPF
- **[Proyecto_Series](C%23/Proyecto_Series)**: Proyecto de gestión de series
- **Ejercicios WPF**: Múltiples ejercicios de práctica con WPF (Ejercicio6_eventos, Ejercicio10_WPF, Ejercicio11_WPF, Ej_9Textblock, Ej13, etc.)
- **Eventos y Delegados**: Ejercicios sobre eventos y delegados en C# (Ej_Delegados_1, Ej_Delegados_2, EventosyDelegados_2, EventosyDelegados_v2, Ej_Inciales_Eventos, Ej_Anonimas)
- **User Controls**: Ejercicios sobre controles de usuario personalizados (Ejercicio1User_Control, Ejercicio2_UserControl)

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura de páginas web
- **CSS3**: Estilos y diseño visual
- **C#**: Desarrollo de aplicaciones
- **WPF (Windows Presentation Foundation)**: Desarrollo de interfaces gráficas en Windows
- **.NET Framework / .NET Core**: Framework de desarrollo
- **XAML**: Lenguaje de marcado para interfaces WPF
- **SQLite**: Base de datos ligera
- **SVG**: Gráficos vectoriales escalables
- **Font Awesome**: Biblioteca de iconos
- **Google Fonts**: Fuentes web
